# Student Grade Tracker 🎓
A Python Command-Line Interface (CLI) application for managing and analyzing student scores.

## Features ✨
- **Add Scores**: Input new student grades with validation (0 - 100).
- **View Scores**: Display all stored grades.
- **Class Statistics**: View Total student count, Average score, Maximum, and Minimum score.
- **Remove Score**: Delete a specific grade from the list.
- **Sort Scores**: Sort grades in ascending order.

## Concepts Used 🧠
- Lists & List Operations (`append`, `remove`, `sort`, `len`, `sum`, `max`, `min`)
- Loops (`while`, `for`)
- Conditional Logic (`if`, `elif`, `else`)
- Input Parsing (`map`, `split`, `float`)
